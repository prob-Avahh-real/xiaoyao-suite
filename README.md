# 逍遥游组曲

七乐章五音套曲，循《庄子·逍遥游》（郭象本）篇内叙事：冥 → 化 → 抟 → 笑 → 椿 → 御 → 游。

| 乐章 | 题 | 调式 |
|------|----|------|
| I | 冥 · 北冥有鱼 | 羽 |
| II | 化 · 化而为鸟 | 角 |
| III | 抟 · 抟扶摇而上 | 徵 |
| IV | 笑 · 蜩与学鸠 | 角 |
| V | 椿 · 大椿八千岁 | 宫 |
| VI | 御 · 列子御风 | 商 |
| VII | 游 · 至人无己 | 宫 |

## 命令

```bash
npm install
npm test
npm start          # http://localhost:5191
npm run sync:android
npm run apk
```

短引出自公有领域《庄子》；旋律为五声音阶手写定稿。
